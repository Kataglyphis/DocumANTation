% Open Source section.
%
% Evidence-first on purpose: "passionate about open source" is a line every CV
% carries. Two upstream PRs with their numbers, their state and the defect they
% fix are checkable in one click, so a reader can verify the claim instead of
% believing it. The credo sentence says why in one line; the columns prove it.
%
% Both PR states are named ("under review", "draft") because neither is merged.
% Relabel when they land -- never silently.
%
% \link swallows the space that follows it: it ends with \color{Black}, and
% xcolor's \color peeks for an optional [model] via \@ifnextchar, which skips
% space tokens. Hence the explicit \ (control space) after every \link here --
% a plain space renders as "#2811(Rust". Fixed at the call site rather than in
% myCV_METADATA.cls, which the book and slides share.
%
% \small throughout with nosep lists: this section is what has to pay for
% itself on a strict one-pager. Two columns, not three -- the upstream entries
% carry a clause of technical detail each and hyphenate badly at
% \threecolumnsection widths.
